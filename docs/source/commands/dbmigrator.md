# dbmigrator

The `dbmigrator` command allows users to migrate leveldb databases to pebbledb.

## Syntax

The `dbmigrator` tool has no sub-commands, but supports flags that can be set
to complete the task.

## dbmigrator
```
usage: dbmigrator --db-path=DB-PATH [<flags>]

Migrate LevelDB databases to PebbleDB.

This tool migrates one or more LevelDB directories to PebbleDB. It must be run
on a stopped peer or orderer node. After migration, only the configuration needs
to be updated.

Typical directories to migrate:

  Peer:
    ledgersData/stateLeveldb
    ledgersData/historyLeveldb
    ledgersData/bookkeeper
    ledgersData/pvtdataStore
    ledgersData/configHistory
    ledgersData/chains/index
    ledgersData/ledgerProvider
    transientstore

  Orderer:
    <ordererDir>/system/index

After migration, remove old LevelDB file lock directories manually because
PebbleDB uses a regular file (syscall.Flock) instead:

  Peer:
    <ledgersData>/fileLock
    <peerFS>/transientStoreFileLock

  Orderer: (none — orderer does not use FileLock)

Flags:
  --help                 Show context-sensitive help (also try --help-long and
                         --help-man).
  --db-path=DB-PATH ...  Path to LevelDB directory to migrate (repeatable)
```

## Usage

### Database migration from leveldb to pebbledb

Transfers the leveldb database to pebbledb, and leaves leveldb in a folder with the bak extension.

```
dbmigrator dbpath
```
